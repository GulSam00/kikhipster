# frontend 구현 완료 — 화면 정리 5건 (2026-09-01)

## 1. 상세 액션 줄 — 세로 2단 중앙

`components/common/DetailActionBar.tsx` 한 곳을 고쳐 탑스터·월드컵 두 상세가 같이 바뀐다.
`justify-between`(좌: 주요 동작 / 우: 좋아요·공유) → `flex-col items-center`(위: 주요 동작 /
아래: 좋아요·공유, 둘 다 가운데).

주요 버튼을 `h-11` → `h-12` 로 키웠다.

- 탑스터 '이미지 저장': `h-12 w-full px-6 sm:w-auto` — 좁은 화면에서는 폭을 채운다
- 월드컵 '랭킹보기': `h-12 px-6`
- `PlayLauncher`: 트리거·버튼 둘 다 `h-12`, 묶음 폭 `w-50` → `w-56`.
  **`data-[size=default]:h-11` 도 `h-12` 로 같이 바꿨다** — CLAUDE.md 에 적힌 twMerge 함정
  그대로다. variant 를 맞춰 덮지 않으면 속성 선택자가 붙은 기본값이 이긴다.

`flex-wrap` 은 유지했다. 없으면 소유자가 모바일에서 열었을 때 가로 스크롤이 난다(과거 사고).

## 3·4. `TrackRow` 재구성 + 곡 커버

**새 순서**: 재생 버튼 → 번호 → (커버) → 제목·아티스트 → 시간 → 하트

**행 전체가 재생 버튼이다.** `absolute inset-0` 로 덮는 진짜 `<button>` 을 형제로 깔았다 —
`AlbumCard` 가 링크로 쓰는 패턴이다. `<div onClick>` 으로 만들면 키보드 접근과 focus ring 을
직접 붙여야 하고(§ Component states — 없으면 BLOCK), 버튼 안에 버튼을 넣는 것은 무효
마크업이라 하트·재생 버튼을 자식으로 둘 수 없다. 미리듣기가 없는 곡은 덮개를 렌더하지
않는다 — 눌러도 안 되는 자리를 누를 수 있게 보이면 안 된다.

하트와 재생 버튼에 `z-10` 을 줘 덮개 위에 둔다. 재생 버튼은 덮개와 동작이 같으므로
`aria-hidden`·`tabIndex={-1}` 로 스크린리더·탭 순서에서 중복을 없앴다.

**커버는 `showCover` 로 켠다.** 앨범 상세는 전곡이 같은 커버라 켜지 않는다(같은 그림이
세로로 반복될 뿐이다). 검색 곡 탭과 아티스트 상세 인기 트랙에서 켠다.

**아티스트 상세에서 버그를 하나 찾아 고쳤다** — `albumCover={artist.image_url}` 을 넘기고
있었는데 그 값은 **항상 null** 이다. 그래서 아티스트 페이지에서 재생을 시작하면 하단
재생기의 커버 자리가 늘 비어 있었다. `t.album.cover_url` 로 바꿨다.

## 5. 월드컵 종류 표시 — 카드 + 상세

- `TournamentCard`: 제목 앞에 `곡` / `앨범` 배지(무채색). 2026-08-27 에 뺀 것은 *수량*
  ('앨범 N')이고 이것은 *종류*다 — 수량은 `ItemStats` 와 겹쳤지만 종류는 겹치는 정보가 없다
- `app/tournament/[id]/page.tsx`: `DetailHeader` 의 `badges` 슬롯에 `앨범 월드컵`.
  **`ITEM_TYPE_LABEL` 이 그동안 OG 설명에만 쓰이고 화면에는 없었다.** 탑스터가 격자 크기를
  넣는 자리를 월드컵은 비워 두고 있었다

대시보드는 카드가 여러 장 깔리는 화면이라 § Color budget 을 지켜 무채색으로 뒀다.

## 확인하지 못한 것

- **`PlayerDock` 볼륨** — 곡이 재생 중일 때만 렌더돼서 SSR 에 없다
- **`TournamentCard` 종류 배지** — 대시보드·프로필이 클라이언트 무한 스크롤이라 SSR 에 카드가 없다
- **탑스터 상세 액션 줄** — Client Component 라 SSR 에 본문이 없다(월드컵과 같은
  `DetailActionBar` 를 쓰므로 구조는 같다)
- **행 클릭 재생이 실제로 도는지** — 클릭 이벤트라 정적 검증 불가
