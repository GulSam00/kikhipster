## 기능 명세

### 1. 검색 (`/search`)

- **탭 구성**: 아티스트 / 앨범 / 곡 (3탭)
- **트리거**: 실시간 검색 (debounce 300ms)
- **히스토리**: 로컬스토리지에 최근 검색어 저장

**아티스트 카드 표시 필드**
- 프로필 이미지, 이름, 장르, 팔로워 수, 인기도(popularity)

**앨범 카드 표시 필드**
- 커버, 앨범명, 아티스트명, 발매년도, 총 트랙수, 앨범 타입(앨범/싱글/EP)

**곡 카드 표시 필드**
- 앨범 커버(썸네일), 곡명, 아티스트명, 앨범명, 재생시간, 인기도, 19금 여부(explicit), 미리듣기 버튼(preview_url 있을 때만)

**필요한 백엔드 추가 작업**
- `GET /api/music/search/tracks?q=` 엔드포인트 신규 추가

---

### 2. 아티스트 상세 (`/artists/[id]`)

**구성**
- 헤더: 프로필 이미지, 이름, 장르, 팔로워 수, 인기도
- 인기 트랙 섹션 (Spotify top-tracks API)
- 앨범/싱글 목록 (커버 그리드)

**동작**
- 앨범 클릭 → 앨범 상세 페이지 이동

**필요한 백엔드 추가 작업**
- `GET /api/music/artists/{id}/top-tracks` 엔드포인트 신규 추가

---

### 3. 앨범 상세 (`/albums/[id]`)

**구성**
- 헤더: 커버, 앨범명, 아티스트명, 발매일, 총 트랙수, 앨범 타입
- 트랙 목록: 트랙 번호, 곡명, 재생시간, 미리듣기 버튼

**동작**
- 뒤로 가기 → 아티스트 상세 페이지로 이동
- 미리듣기: 하단 고정 미니 플레이어 (이전/다음 트랙 이동 가능)

---

### 4. 탑스터 에디터 (`/topsters/new`)

**구성**
- 제목/설명 입력 필드
- 격자 크기 선택: 3×3 / 4×4 / 5×5
- 앨범 검색 → 격자에 드래그앤드롭 배치
- 공개/비공개 설정
- 저장 후 공유 링크 생성
- 완성된 탑스터 이미지 다운로드 (html2canvas)

**제약**
- 항목 단위: 앨범만 (곡 단위 불가)
- 로그인 필요

---

### 5. 탑스터 상세 (`/topsters/[id]`)

**구성**
- 탑스터 그리드 뷰 (제목, 설명 포함)
- 좋아요 버튼
- 댓글 목록 + 댓글 입력 (로그인 필요)

---

### 6. 토너먼트 (`/tournament`)

**구성**
- 풀 구성 방식 선택:
  - 특정 아티스트 전곡 자동 추가
  - 사용자가 직접 곡 선택
- 토너먼트 규모 선택: 8강 / 16강 / 32강
- 대결 화면: 두 곡 나란히 표시, 미리듣기(30초) 지원
- 결과 화면: 최종 우승곡 + 결과 공유

**로그인 필요**

---

### 7. 감성 태그 리액션 (구현 범위 제외, 2026-08-27)

> ⚠️ **이번 구현 범위에서 뺐다.** 안 만들기로 확정한 게 아니라 착수 계획이 없는 상태다 —
> 나중에 추가할 수도 있다. 되살릴 땐 아래 기획을 그대로 쓰지 말고 처음부터 다시 본다
> (2026-07-06 이후 손대지 않은 문서다).
>
> 같은 자리를 놓고 경쟁하던 **텍스트 리뷰**(앨범/아티스트/트랙 대상 별점 + 텍스트)도 함께
> 범위에서 뺐고, CLAUDE.md 목표 문장에서도 "리뷰"를 지웠다. 둘 다 `docs/TASKS.md`
> **"언젠가 (지금은 안 만든다)"** 섹션에 있다 — 앨범/곡 평가를 되살린다면 **둘 중 어느 쪽인지부터**
> 정해야 한다.

**개요**: 텍스트 리뷰 대신 감성 태그 다중 선택으로 앨범/곡 평가

**태그 대상**: 앨범, 곡

**태그 목록**

| 카테고리 | 태그 |
|----------|------|
| 분위기 | 신나요 🔥 / 잔잔해요 🌊 / 설레요 💕 / 위로가 돼요 🫂 / 슬퍼요 😢 / 몽환적이에요 🌙 |
| 장르 느낌 | 힙해요 😎 / 팝스러워요 ✨ / 록 느낌이에요 🎸 / 재즈 느낌이에요 🎷 / R&B 느낌이에요 🎵 |
| 상황 | 드라이브할 때 🚗 / 공부할 때 📚 / 운동할 때 💪 / 잠들기 전 🌙 / 파티할 때 🎉 |
| 완성도 | 처음부터 끝까지 명곡이에요 💎 / 타이틀곡이 최고예요 🏆 / 숨겨진 명곡이 있어요 🔍 |

**동작**
- 로그인 유저: 태그 클릭 → 선택/해제 토글 (다중 선택 가능)
- 비로그인: 집계 결과만 열람
- 태그별 선택 인원 수 + 비율 바 표시

---

### 8. 댓글

- **대상**: 탑스터만
- **대댓글**: 없음 (단일 depth)
- **수정/삭제**: 본인만 가능
- **로그인 필요**

---

### 9. 좋아요

- **대상**: 탑스터, 앨범, 곡, 댓글, 아티스트
- **로그인 필요**
- 비로그인 시 좋아요 수는 표시, 클릭 시 로그인 유도

---

### 10. 인증

- **방식**: Google, Kakao 소셜 로그인
- **비로그인 허용**: 검색, 아티스트/앨범/탑스터 조회
- **로그인 필요**: 태그(§7 — 범위 제외), 좋아요, 댓글, 탑스터 생성, 토너먼트

## 백엔드 추가 필요 엔드포인트 요약

| Method | Path | 설명 |
|--------|------|------|
| GET | `/api/music/search/tracks?q=` | 곡 검색 |

---

### 11. 홈 페이지 (`/`)

- **로그인 전/후**: 동일 화면
- **배너**: 없음
- **섹션 구성** (순서대로):
  1. 인기 탑스터 (좋아요 순)
  2. 최근 등록된 탑스터
  3. 진행 중인 토너먼트
  4. 인기 아티스트
  5. 신규 앨범 (최근 발매)

---

### 12. 프로필 페이지 (`/profile`, `/profile/[userId]`)

- **내 프로필 표시 정보**:
  - 내가 만든 탑스터 목록
  - 좋아요한 탑스터 / 앨범 / 곡 / 아티스트
  - 참여한 토너먼트 결과
- **타인 프로필**: `/profile/[userId]` 로 열람 가능
- **프로필 편집**: 닉네임만 수정 가능 (프로필 이미지 없음 — 부적절한 이미지 이슈, 서버 저장 이슈)
