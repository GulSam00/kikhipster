### T5. 기능 요청 (2026-08-27 접수) — 6건 전부 완료

상세는 `docs/WORKLOG.md` 세션 기록 참조. 남은 후속은 아래에만 적는다.

- [ ] **플레이 화면을 브라우저로 확인하지 못했다 (2026-08-27).** 카드 확대·배경 대진표·전환 버튼·
  올라가는 애니메이션은 페이지가 Client Component 라 SSR HTML 로 검증할 수 없고 playwright 도 없다.
  `tsc`·`next build`·응답 200 까지만 확인했다 — **실제 동작과 모양은 사람이 한 번 봐야 한다**
- [ ] **상세 UI 통일 결과를 브라우저로 확인하지 못했다 (2026-08-27).** 소유자 메뉴(`⋯` 드롭다운)는
  로그인 소유자에게만 열리고, 탑스터 상세는 Client Component 라 SSR HTML 에 본문이 없다.
  **직접 눌러 봐야 하는 것**: ⋯ 메뉴가 열리는지 · 삭제가 토스트 확인까지 2단계로 가는지 ·
  상세의 '이미지 저장'이 실제 PNG 를 내려주는지 · `max-w-4xl` 로 좁힌 탑스터 캔버스가
  답답하지 않은지(원래 `max-w-5xl` 이었다) · **`PlayLauncher` 의 select 를 열어 강수를 바꾸고
  시작이 되는지**(POST→`/play/{id}` 경로 자체는 curl 로 200 을 확인했다) · **펼쳐진 목록이
  컨트롤 바로 아래에 같은 너비로 뜨는지** — `SelectContent` 는 Portal 이라 열기 전엔 DOM 에 없다
- [ ] **에디터 두 개가 아직 크다 (2026-08-28).** `TopsterEditor` 578줄 / `TournamentEditor` 577줄로
  둘이 프론트 전체의 13%다. 한 파일에 검색·풀 관리·드래그앤드롭·옵션 편집·저장이 다 있고
  훅 호출이 각각 15~17개다. 상태 로직을 `useTopsterDraft()` / `useTournamentDraft()` 로 빼면
  UI 만 남는다 — 파일이 크게 움직여서 lib 재편과 분리해 뒀다
- [ ] **월드컵 편집기의 '빼기' 오버레이를 눈으로 확인하지 못했다 (2026-08-28).** 담긴 목록은
  항목을 담아야 나타나서 SSR 로는 빈 상태만 보인다. 타일에 hover·키보드 포커스했을 때
  딤과 X 가 뜨는지, 클릭이 실제로 빼는지 봐야 한다
- [ ] **재생기를 브라우저로 확인하지 못했다 (2026-08-28).** 큐·시크·드래그 재정렬·자동 다음 곡은
  전부 클라이언트 상태라 SSR HTML 로는 검증할 수 없다. `tsc`·`next build`·페이지 200·
  SSR 에 재생 버튼이 찍히는 것까지만 확인했다. **직접 해 봐야 하는 것**: 곡을 누르면 하단에
  재생기가 뜨고 자동 재생되는지 · 곡이 끝나면 다음 곡으로 넘어가는지 · 슬라이더로 위치가
  옮겨지는지 · 이전/다음 버튼 · 재생목록을 펼쳐 손잡이(⠿)로 순서를 바꿔도 재생이 안 끊기는지 ·
  재생 중인 곡을 목록에서 뺐을 때 다음 곡이 이어지는지
- [ ] **앨범 수록곡을 검색으로 채우는 경로는 전곡을 보장하지 않는다 (2026-08-28).** KR 앨범은

- [ ] **예전에 담긴 싱글·EP 후보는 그대로 남아 있다.** 싱글·EP 제외 필터(2026-08-23)보다 먼저
  만든 월드컵의 후보 목록에는 `- Single` / `- EP` 항목이 들어 있다. 검색 경로는 이미 막혀 있어
  **코드가 아니라 데이터 문제**다 — 그 월드컵을 수정해서 빼거나, 일괄 정리 스크립트를 짜야 한다
