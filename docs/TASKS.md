
**git 에 안 들어가는 것 3종** — 새 PC에서 직접 만들어야 한다:

| 대상 | 조치 |
|------|------|
| `backend/.env` · `frontend/.env.local` · 루트 `.env` | 전부 `.gitignore` 대상. OAuth 키(Google·Kakao REST API 키)·DB URL·JWT 시크릿을 다시 채운다 |

| `node_modules` | **`cd frontend && pnpm install`. `npm install` 을 쓰면 안 된다** — 이유는 CLAUDE.md |

띄우는 법은 루트에서 `npm run dev` 하나면 된다(DB→마이그레이션→백엔드→프론트).

## 언젠가 (지금은 안 만든다)

착수 계획이 없는 것들이다. **"진행 예정"이 아니다** — 다시 꺼낼 땐 기획부터 다시 본다.
여기 있다는 건 "안 만들기로 확정"이 아니라 **이번 구현 범위에서 뺐다**는 뜻이다.

- [ ] **리뷰 (앨범/아티스트/트랙 대상 별점 + 텍스트)** — 2026-08-27 구현 범위에서 제외.
  모델·라우터·페이지·기획 전부 부재였고, **CLAUDE.md 목표 문장에서도 뺐다**(이제 목표는
  검색·탑스터·토너먼트·댓글·좋아요 5종). `Comment` 는 8/22에 `(target_type, target_id)` 범용 구조가
  돼서 대상 확장 자체는 되지만 **별점 컬럼이 없어** 리뷰를 대체하지는 못한다 — 되살리려면
  모델부터 새로 판다
- [ ] **아티스트 인물 사진 — 방향만 정해 뒀다 (2026-09-01). 착수 계획은 없다.**
  iTunes 아티스트 엔티티에 이미지 필드가 아예 없어 `image_url` 이 전건 `None` 이다.
  실측 조사 후 **출처는 Deezer 단독 · 저장은 원본 URL 참조(`next/image` 재캐시) ·
  적용은 아티스트 상세만** 으로 정했다. 자체 호스팅(S3+CloudFront)은 하게 되더라도
  T4 와 함께 본다. **화면은 `image_url` 문자열 하나만 보므로 저장 계층은 나중에
  갈아끼워도 되돌리는 비용이 없다** — 그래서 지금 더 정할 게 없다.

  다시 꺼낼 때 재조사하지 않아도 되게, 실측으로 확인한 것만 남긴다:
  - **Spotify 는 후보가 아니다** — 2026-08-20 에 403 `Active premium subscription required`.
    **Last.fm 도 아니다** — 2019년부터 전 아티스트에 같은 플레이스홀더를 준다
  - **Deezer 는 아티스트명 단독 조회에선 정확하다.** 2026-08-21 에 Deezer 를 검색 API 로
    탈락시킨 사유는 *혼합 쿼리*(`"아이유 Blueming"` 0건)였고, 이름 단독은 한글·일본어 모두
    정확히 찾는다(`아이유`→IU, `뉴진스`→NewJeans, `米津玄師`→Kenshi Yonezu). 다른 실패 모드다
  - **함정 ①: 1위가 정답이 아니다.** `김광석` 은 1위가 `nb_fan=30` 인 유령 항목이고 진짜는
    2위(`nb_fan=482`)였다. 정규화 이름 완전일치 우선 → 동률이면 `nb_fan` 최대
  - **함정 ②: '사진 없음'이 200 으로 온다.** URL 해시 자리가 비었거나
    `d41d8cd98f00b204e9800998ecf8427e`(= **빈 문자열의 MD5**)면 사진이 없는 것이고,
    둘 다 같은 16802B 회색 이미지를 준다. **URL 문자열만 보고 걸러진다 — 추가 요청 불필요**
  - **MusicBrainz→Wikidata→Commons 도 동작은 한다**(아티스트당 3요청, CC 라 출처 표기 의무).
    다만 1req/s 를 지켜도 버스트에 503 을 실측했다 — 목록용이 아니라 배치용이다
  - 매핑(`itunes_artist_id` → Deezer id)에는 TTL 을 안 건다. 아티스트 동일성은 안 변하므로
    **요청 비용은 신규 아티스트에게만** 든다
- [ ] **감성 태그 리액션** — `_workspace/planning.md` §7. 텍스트 리뷰 대신 정해진 태그
  (분위기·장르 느낌·상황·완성도 4카테고리 19종)를 다중 선택 토글하고 비율 바로 집계를 보여주는 안.
  2026-07-06 보류 이후 진척 없음. **위 리뷰 항목과 같은 자리를 놓고 경쟁하는 대안**이라 함께 보류한다 —
  나중에 "앨범/곡 평가"를 되살린다면 둘 중 어느 쪽인지부터 정해야 한다
