## 현재 구현 범위 (2026-08-27 기준)

무엇이 이미 있는지 모르면 중복 구현하게 되므로 여기 둔다.

| 도메인 | 구현된 것 |
|--------|----------|
| **인증** | Google·Kakao OAuth, JWT 발급/갱신, `/api/auth/me`, 공개 프로필 조회. 토큰은 프론트 `localStorage` |
| **음악** | **ID 배치 조회**(`GET /api/music/tracks?ids=`, `GET /api/music/albums?ids=` — 최대 512개, 내부에서 150개씩 청크, **`music_cache` DB 캐시 경유** — 데이터 30일 / '없음' tombstone 1일 TTL). 아티스트/앨범/곡 검색(**앨범 검색은 싱글·EP 제외가 기본**, `include_singles=true` 로 해제), 아티스트 상세, **아티스트 앨범 목록(같은 싱글·EP 필터 적용)**, 아티스트 트랙 목록, 앨범 트랙 목록 — **iTunes Search API 기반, 인증 키 불필요**. **단건 조회 경로도 캐시를 탄다**(아티스트 상세·앨범 트랙 30일, 아티스트 앨범·트랙 목록 1일 — 목록은 신보가 나오면 바뀐다). **검색 결과는 배치 캐시에 미리 적힌다**(write-through). 만료 행은 앱 기동 시 정리한다. 팔로워 수·인물 사진 없음(마이크 아이콘 폴백), "인기 트랙"은 진짜 인기순 아님(iTunes에 popularity 개념 자체가 없음) |
| **탑스터** | 생성(**비정방형 격자 width×height, 최대 5×5 — 칸이 늘어도 전체 크기 고정**, 공개·비공개), **목록(검색 + 최신순·인기순 — 인기는 좋아요 수 기준)**, 상세, 수정, 삭제, 유저별 목록, 내 목록. **실제 앨범 커버 렌더**(목록·홈·프로필·상세), **격자 옆 `아티스트 – 앨범` 목록**, **표시 옵션 8종**(제목/제목표시/앨범정보표시/넘버링/배경색/**글자색**/간격/공개), **앨범 정보가 격자 행에 세로 정렬**, **저장 전 PNG 다운로드**(캔버스 직접 렌더) |
| **댓글** | 목록/작성/**수정**/삭제 — 화면까지 전부 있다. **`(target_type, target_id)` 범용 구조**(topster·tournament) — `/api/comments/{type}/{id}`. 기존 `/api/topsters/{id}/comments` 경로도 그대로 유지. **본문이 실제로 바뀔 때만 `edited_at` 을 찍고 화면에 `(수정됨)`** 을 붙인다. **댓글 영역은 탑스터 상세와 월드컵 상세 두 곳에 붙어 있다** — 같은 `CommentSection` 을 `targetType` 만 바꿔 쓴다 |

| **월드컵** | **정의와 플레이가 분리된 구조.** 월드컵 = 이름·설명·타입(곡\|앨범)·풀(4~512). 생성/조회/**수정**/**삭제** — 화면까지 전부 있다(`/tournament/[id]/edit`, 종류는 못 바꾼다). 대시보드 목록(검색 + 최신순·인기순 전체/년/월 — 인기는 플레이 횟수 기준), **유저별 목록 `GET /user/{id}`·내 목록 `GET /me/list`**. 플레이 = `POST /{id}/plays`로 풀에서 강수(4~128)만큼 무작위 추출 → `/api/plays/{id}` 조회·투표. **비로그인 플레이 허용**(`plays.user_id` nullable). 랭킹 `GET /{id}/ranking` — 우승 비율·승률 + 7일 전 대비 추이 (**집계는 SQL에서 한다** — 라운드의 a/b 칸을 UNION ALL 로 펼쳐 group by) |
| **프론트** | 페이지 17개 — `/`, `/search`, `/artists/[id]`, `/albums/[id]`, `/topsters`, `/topsters/new`, `/topsters/[id]`, **`/topsters/[id]/edit`**, `/tournament`, **`/tournament`(대시보드)**, **`/tournament/new`(3단계 위저드)**, **`/tournament/[id]`**, **`/tournament/[id]/edit`**, **`/tournament/[id]/ranking`**, **`/play/[playId]`**, `/profile`, `/profile/[userId]`, `/login`, `/auth/callback`. `PlayerContext` + `MiniPlayer` 로 30초 미리듣기. **탑스터 목록·월드컵 대시보드·프로필(내·유저별) 모두 무한 스크롤**(`lib/use-infinite-list.ts` — offset 기반, 응답이 `limit` 미만이면 마지막 페이지로 판정. 실패하면 자동 로딩을 멈추고 '다시 불러오기' 버튼을 낸다). **탑스터는 `TopsterEditor`, 월드컵은 `TournamentEditor` 를 만들기·수정이 공유한다.** **프로필에는 내 탑스터와 내 월드컵이 함께 나열되고 카드마다 수정·삭제가 붙는다**. **월드컵 상세의 후보는 앞 24개를 SSR 로 내려주고 나머지는 '더 보기'(48개씩)로 이어 받는다** |
