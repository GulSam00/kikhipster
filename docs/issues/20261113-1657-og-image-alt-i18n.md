## 맥락

`20261113-1630-i18n-ui-strings-next-intl` 에서 UI 문자열을 next-intl 메시지로 옮겼지만
`app/topsters/[id]/opengraph-image.tsx`·`app/tournament/[id]/opengraph-image.tsx` 의 `export const alt`
('탑스터 미리보기'·'월드컵 미리보기')는 모듈 상수라 요청별 locale 을 읽을 수 없어 한국어로 남겼다.
이미지 본문(kind·subtitle)은 `getTranslations` 로 옮겼다.

locale 별 alt 를 주려면 `generateImageMetadata` 로 바꿔야 하는데, 그러면 이미지 URL 에 id 세그먼트가 붙어
라우트 모양이 바뀐다(`/topsters/-/opengraph-image` → `/topsters/-/opengraph-image/<id>`). 크롤러는 쿠키 없이
오므로 대부분 `ko` 로 해석된다는 점도 고려해 우선순위를 정할 것.
